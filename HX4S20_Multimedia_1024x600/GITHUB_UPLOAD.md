# GitHub代码包说明

本目录来自正式工程 HX4S20_Multimedia_1024x600 的当前文件，整理上传日期为2026年11月1日。上传时未修改RTL、约束或原工程配置，未运行综合、布局布线，也未操作开发板。

## 使用

- 目标器件 EG4S20BG256，显示分辨率1024×600，使用安路TD 6.2.1。
- 从本目录作为工作目录使用 sources.f 与 build.tcl；当前入口默认综合，BUILD_STAGE=route选择实现。构建需自行安装TD及其授权IP支持。
- AL和PRJ保留原工程内容，包括原本的Z盘工程路径；换电脑后应在TD中设置实际工程位置，核对当前源文件条目及面积优先参数。
- ROM字模、动画、Logo初始化文件和IP配置随代码保留。sim中包含测试源及compact局部验证记录；tools/run_compact_tests.py保留原本本地Icarus工具路径，运行前按环境设置。
